# Operating Systems (BCS303) — VTU Important Questions

This repo has **exam-ready, structured answers** for VTU 3rd semester "Operating
Systems" (BCS303) — starting with **Module 1: Introduction to Operating
Systems**.

Source material: 9 previous-year/model BCS303 question papers (Dec 2023 → Dec
2025, + Model Paper) + the Silberschatz "Operating System Concepts" textbook
(Chapter 1) + the official vtucode.com Module 1 notes. This is a theory-heavy
module (no C programs) — explanations use plain definitions, bullet points, and
ASCII diagrams where the question asks for one.

## ⚠️ Note on source papers

Two different question papers in the source files were both labeled
"Dec.2023/Jan.2024" but contain **different questions** — they're kept as
separate files here: **Set A** and **Set B**. Two other files sent
("June/July 2025", non-makeup) were **identical duplicates** of the same paper
— only one Question-Answer file covers both.

## How every answer is structured

1. **Definition** — one or two lines, exam-safe.
2. **Points** — 5 to 10 easy bullet points explaining it.
3. **Diagram** — ASCII diagram wherever the question asks for one.
4. **Comparison table** — for "differentiate/distinguish" questions.

## Why three formats

- **Question-Answer** files let you revise **by paper** — exact wording from the
  source papers, answer immediately below.
- **Topic-organized** files let you revise **by concept** — no duplicate answers
  across papers that ask the same thing differently.
- The **Cheat Sheet** is the fastest pre-exam skim — every term's definition in
  one place, with a one-line summary table at the end for quick recall.
